# Calendar + To-Do Desktop App (Electron)

A small desktop app that shows today’s date and a simple to-do list.  
You can add tasks, mark them as done, and delete them. Tasks are saved in `localStorage`, so they stay after restarting the app.

## Features
- Displays current day and month
- Add tasks (button or press **Enter**)
- Toggle completed tasks (click a task)
- Delete tasks (click **x**)
- Persists tasks using `localStorage`
- Minimal frameless Electron window

## Tech Stack
- Electron
- HTML / CSS / JavaScript

## Run Locally
```bash
npm install
npm start
```
